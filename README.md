
# Release Notes — v1.1.0

## Added
- Додано спеціальний тариф доставки для міста Kyiv — 80.0.
- Додано можливість явно передавати ставку податку taxRate.
- Додано окрему функцію для обробки рахунків без податку.

## Changed
- Коефіцієнт вартості доставки за кожен кілограм збільшено з 12.0 до 15.0.
- Виконано рефакторинг архітектурної зв'язності.
- Перехід від Common, Stamp та Control Coupling до Data Coupling.
- Функція розрахунку доставки тепер отримує місто та вагу окремими параметрами.

## Breaking Changes
- Змінено сигнатуру функції calculateDeliveryCost().
- Функцію processInvoice() замінено на processStandardInvoice() та processTaxExemptInvoice().
- Видалено глобальну змінну GLOBAL_TAX_RATE.
- Видалено параметр modeFlag.
- Код, який використовував старі функції, потрібно оновити.
